About EventBook

A web-based event booking system for browsing events, selecting seats, and managing bookings — with a full admin dashboard.

📁 Group 1 📅 2026 🛠 Vanilla JS + jQuery 💾 localStorage
On this page
Features Getting Started Default Accounts Tech Stack Pages & Flow Project Structure Notes Group Members
🚀

Features

👤 Customer

  • Register and log in as a customer
  • Browse available events on the dashboard
  • Select seats from an interactive seat map
  • Checkout with GCash, PayMaya, or Bank Transfer
  • View booking history and ticket with QR code
  • Cancel, restore, or delete bookings
  • Reset forgotten password

🔑 Admin

  • Log in directly — no sign up needed
  • Register, edit, and delete events
  • View all customer transactions
  • Live dashboard stats: events, bookings, revenue
  • Occupancy rate per event with progress bars
  • Recent transaction activity feed
🧭

Getting Started

No installation or server required. Just open index.html in Chrome and follow the steps below.

👤 Accessing the Customer Dashboard

⚠️ You must sign up first before you can log in as a customer, even when using the default credentials.
1

Open index.html and click Sign Up

2

Fill in the registration form using these credentials:

Full Name User Example Email user@example.com Password 12345678
3

Click Register — you will be redirected to the login page

4

On the login page, enter your credentials and select Customer as Account Type

Email user@example.com Password 12345678 Type Customer
5

Click Log In — you will be taken to the Customer Dashboard

🔑 Accessing the Admin Dashboard

ℹ️ The admin account is built-in — no sign up required. Just go straight to login.
1

Open index.html and click Sign In

2

Enter the admin credentials and select Admin as Account Type:

Email admin@example.com Password admin123 Type Admin
3

Click Log In — you will be taken to the Admin Dashboard

Pages & Flow

index.html — Home
Landing page with Sign Up and Sign In buttons
signup.html → login.html — Authentication
Register a new account, then log in with email, password and account type
user_dashboard.html — Customer Dashboard
Browse all available events as cards; click View Details to continue
event_details.html — Seat Selection
View event info and pick seats from the interactive seat map
checkout.html — Checkout & Payment
Review booking summary, choose payment method, complete purchase
ticket.html — View Ticket
See your ticket with event details and scan the generated QR code
booking.html — My Bookings
Manage all bookings — cancel, restore, delete, or view ticket
admin_dashboard.html — Admin Panel
Manage events and transactions; view live revenue and occupancy stats

Notes

⚠️All data resets when the browser's localStorage is cleared. There is no permanent database.
🪑The seat map reads real booked seat data — seats purchased by any user are marked unavailable for everyone else.
📅Default events load automatically when a user first logs in, so events are visible without needing the admin to add them first.
🌐Works best on Google Chrome. No internet connection required after the page loads (except for Google Fonts).
